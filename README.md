# Beauty Saloon Appointment System

A web-based application designed to manage salon appointments, services, and staff efficiently. This system allows customers to book appointments online while providing administrative tools for managing salon operations.

## About the Project

The Beauty Saloon Appointment System is developed to simplify the process of appointment booking and salon management.

Key objectives:
- Improve customer convenience in booking services
- Reduce manual scheduling errors
- Provide an organized system for staff management
- Centralize all salon operations in one platform

---

## Features

### Customer Features
- User registration and login
- Browse available services
- Book appointments
- View appointment history

### Admin and Staff Features
- Manage services (Create, Read, Update, Delete)
- Manage staff and beauticians
- View and control appointments
- Dashboard for system overview

### Appointment System
- Real-time booking
- Appointment status tracking
- Conflict handling for time slots
